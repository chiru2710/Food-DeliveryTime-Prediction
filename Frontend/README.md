# Food Delivery Time Prediction Frontend

Professional responsive frontend with animated UI, form validation, and live FastAPI integration.

Production API:
https://food-deliverytime-prediction-7gph.onrender.com/predict

Swagger:
https://food-deliverytime-prediction-7gph.onrender.com/docs

## Run locally
Open with VS Code Live Server, or:
```bash
python -m http.server 5500
```
Then visit http://127.0.0.1:5500
